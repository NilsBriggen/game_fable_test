Probes: `tools/critic/probes/world/{eviction-race,skirt-coverage,vegetation-capacity}.test.ts` (new; run via
`npx vitest run --config tools/critic/probes/world/vitest.config.ts`). All three fail/assert against real
source (skirt-coverage genuinely fails; the other two assert the buggy behavior holds).
